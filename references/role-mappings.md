# 岗位内容映射

仅在判断岗位相关性和项目取舍时读取。所有内容仍需通过事实账本验证。

## 客户成功 / 项目交付

优先证据：

- 客户核心对接、需求澄清和业务流程梳理；
- 项目计划、系统集成、联调、上线和验收；
- 客户 IT、业务、产品、研发和合作伙伴之间的资源串联；
- 上线后的使用跟进、价值实现、续约或口碑，仅在有直接证据时写；
- 交付流程、SOP、服务标准和风险管理，仅在实际做过时写。

压缩内容：

- 与客户价值无关的底层技术细节；
- 没有客户、交付或业务结果的个人工具项目。

## B 端技术支持

优先证据：

- KA 客户支持、开放平台和 API/SDK 接入；
- 日志、接口、字段、环境配置和数据流排查；
- 客户问题分析、影响范围判断、需求回流和版本验收；
- API 文档、FAQ、版本说明、排障手册和知识库；
- On-call、SLA 和问题分级只有确认后才能写。

压缩内容：

- 与问题定位无关的售前宣讲；
- 缺少支持场景的泛化 AI 工具。

## 售前解决方案

优先证据：

- 与销售同行拜访客户；
- 技术交流、需求挖掘、方案设计、宣讲和产品演示；
- Demo、POC、技术选型和立项结果；
- 行业方案标准化、内部培训、竞品和产品反馈；
- API/SDK、系统集成和研发背景作为技术可信度证据。

压缩内容：

- 上线后的日常维护细节；
- 与目标产品场景无关的研发模块。

## AI 售前 / AI 解决方案

优先证据：

- 客户 AI 场景发现、Demo、POC 和商业价值验证；
- LLM、RAG、Agent、工作流、Prompt、模型 API 和效果评测；
- AI 项目边界、数据安全、幻觉控制和交付风险；
- 可运行的个人 Demo 可证明动手能力，但不能替代客户 AI 项目。

严格边界：

- 用过 ChatGPT、Claude Code 或 Codex，不等于做过 Agent 或 Prompt 调优；
- 内部知识库不等于客户侧 AI POC；
- 个人项目不能表述为商业化交付。

## 方案架构师 / FDE

优先证据：

- 复杂业务拆解、架构方案、接口边界和数据链路；
- 客户现场问题定位、原型开发和生产落地；
- 研发、产品、客户与合作伙伴之间的技术决策；
- 可验证的代码、架构和部署能力；
- 从单项目能力抽象为平台或标准方案。

压缩内容：

- 只体现沟通、没有技术决策的描述；
- 与目标行业和技术栈无关的工具罗列。

## 研发岗位

优先证据：

- 具体模块、技术栈、架构决策和个人贡献；
- 性能、稳定性、数据规模、质量和交付结果；
- 线上问题、兼容性、迁移和工程化能力；
- 业务价值作为结果，不用客户沟通替代技术深度。
