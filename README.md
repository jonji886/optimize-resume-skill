# optimize-resume - 简历深度优化助手

> Claude Code Skill：猎头 + 面试官双视角，针对岗位 JD 对简历进行深度诊断与精益改写。不只让简历好看——让它经得起追问。

## 功能简介

这个 Skill 模拟一位 10 年经验的资深技术猎头 + 业务面试官，为你的简历提供两阶段优化服务：

### 第一阶段：深度诊断（5 项全覆盖）
- **硬伤扫描**：跳槽频率 / 空窗期 / 职级趋势 / 行业连续性，给出处理策略
- **核心需求拆解**：硬技能 + 软素质 + 职级信号 + 行业标签
- **ATS 三维度匹配**：关键词 + 职级信号 + 行业标签，提升机器筛选通过率
- **红黑榜分析**：亮点与缺失项精准定位
- **STAR 断点提问**：针对缺口挖掘隐藏经历

### 第二阶段：精益改写
- **彻底去 AI 腔**：禁用空洞动词和形容词，改用肌肉感动词
- **Scope 分级**：每条经历标注参与层级，杜绝低 scope 夸大用词
- **面试钩子设计**：每条核心 bullet 埋设可追问入口，引导面试进入主场 ⭐
- **技术决策展示**：不只写结果，还写为什么选、踩过什么坑
- **软素质行为化**：用可验证的行为证据替代形容词堆砌
- **反过度包装**：平衡完美感与可信度，杜绝"20 条完美 bullet"
- **个人优势精简**：5–6 条、每条 ≤ 2 行，同类合并、去修饰语，HR 10 秒扫读即抓住重点
- **数据量化 + ATS 三维匹配 + 技术→业务价值闭环**

## 安装

将 `SKILL.md` 复制到你的 Claude Code skills 目录：

```bash
cp SKILL.md ~/.claude/skills/optimize-resume/SKILL.md
```

或使用 `gh skill install` 命令安装。

## 使用方法

在 Claude Code 对话中提供：

1. **目标岗位 JD**（文本或文件路径）
2. **你的原始简历**（文本或文件路径）

然后说「帮我优化简历」，Skill 会自动启动两阶段流程。

输出文件将保存为：`姓名-{岗位名称}.md`

## 与普通简历优化的区别

| 维度 | 普通优化 | 本 Skill |
|---|---|---|
| 视角 | 单猎头视角 | 猎头 + 面试官双视角 |
| 硬伤检测 | 无 | 5 项自动扫描 + 处理策略 |
| Scope | 不区分 | 4 级分层，动词匹配 |
| 面试准备 | 无 | 钩子设计 + 技术决策展示 |
| 可信度 | 追求完美 | 反过度包装，平衡真实性 |
| ATS | 关键词 | 三维度（词 + 职级 + 行业） |

## 注意事项

- 禁止编造任何百分比、倍数、金额数据
- 推断内容会用 `<!-- TODO: 待用户确认 -->` 标注
- 输出文件名模板请根据实际情况修改
