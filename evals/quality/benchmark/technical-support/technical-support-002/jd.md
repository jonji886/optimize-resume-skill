技术支持工程师（私有化部署方向）

职责
- 支持客户私有化环境的技术问题排查，覆盖部署、配置与升级场景；
- 处理客户工单并按 SLA 升级，输出问题闭环记录；
- 编写部署手册、巡检清单与故障处理指引；
- 使用脚本自动化部署与巡检，减少重复人工操作；
- 配合研发完成补丁验证与现场问题定位。

要求
- 3 年以上私有化部署或现场技术支持经验；
- 熟悉 Docker 与容器化部署，理解 Kubernetes 基本概念；
- 熟悉 Linux 与 Shell，能写 Python 运维脚本；
- 有客户沟通经验，能把技术问题解释清楚；
- 能承受客户现场压力，有清晰的问题定位方法论。

加分项
- 有数据库调优与高可用架构经验；
- 有客户培训与知识转移经验。
