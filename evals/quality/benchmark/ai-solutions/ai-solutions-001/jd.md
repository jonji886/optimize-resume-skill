AI 解决方案工程师

岗位概述
面向企业客户，把 AI 能力（Agent / RAG）转化为可落地的解决方案，并推动方案在产品侧成型。

职责
- 与客户业务与 IT 团队对接，梳理业务场景与系统现状，输出 AI 解决方案；
- 完成第三方系统 API 集成方案设计与联调，明确鉴权、字段与错误码口径；
- 用 Python 编写方案验证原型与效果评测脚本；
- 沉淀行业解决方案模板，复用至同类客户场景。

要求
- 有面向企业客户的需求梳理与方案输出经验；
- 熟悉 OpenAPI / Webhook 集成，能处理接口层面的实际问题；
- 熟悉 Python，能独立完成原型验证；
- 了解 Agent、RAG，有实际动手经验更佳；
- 表达清晰，能把技术方案讲给非技术听众。

加分项
- 有 MCP 或工具调用实践经验。
