AI 解决方案工程师（Agent 应用方向）

职责
- 面向企业客户设计并交付 Agent / RAG 应用解决方案；
- 与客户业务团队澄清需求边界，拆解为可交付的功能范围；
- 完成大模型 API 与内部系统的集成，处理限流、重试与降级；
- 搭建效果评测脚本，量化回答质量与边界表现；
- 输出方案文档与交付说明。

要求
- 3 年以上后端或应用开发经验，Python 熟练；
- 有 RAG 与 Agent 的实际开发经验；
- 有面向非技术相关方澄清需求并交付的经验；
- 熟悉 FastAPI 或其他 Python Web 框架；
- 有测试或评测意识，能量化验证效果。

加分项
- 熟悉 Kubernetes；
- 有 MCP 或工具调用经验；
- 有客户现场交付经验。
