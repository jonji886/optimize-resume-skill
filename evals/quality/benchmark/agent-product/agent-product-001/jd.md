Agent 应用工程师（Agent 产品方向）

岗位概述
负责 Agent 产品的能力建设：把模型能力编排成可靠、可评测、可上线的产品功能。

职责
- 设计并实现 Agent 工作流，包括工具调用、结果校验与失败回退；
- 建设 RAG 检索链路，提升知识召回与答案准确性；
- 搭建效果评测体系，用测试集量化回答质量与边界表现；
- 对接大模型 API，处理限流、重试、降级与成本控制；
- 与产品协作澄清需求边界并拆解迭代任务。

要求
- 3 年以上 Python 开发经验，熟悉 FastAPI 等 Web 框架；
- 有 Agent / LangChain 或同类编排框架的实际开发经验；
- 有 RAG 落地经验；
- 有评测意识，能量化验证效果；
- 具备工程规范意识（测试、代码评审）。

加分项
- 有 MCP 或工具协议实践经验；
- 有生产环境容器化部署经验。
