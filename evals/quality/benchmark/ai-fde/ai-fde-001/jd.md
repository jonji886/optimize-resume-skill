AI Forward Deployed Engineer（AI 前向交付工程师）

团队与岗位
我们为大型企业客户交付 AI Agent 解决方案。这个岗位需要直接走进客户现场，
把客户模糊的业务诉求变成可上线、可验收的 AI 交付物，而不是只写文档。

职责
- 面向企业客户完成 AI 方案的落地交付，从需求澄清、方案设计到上线验收；
- 负责第三方系统 API 集成与接口对接，处理鉴权、字段口径与联调问题；
- 使用 Python 编写工具脚本、数据准备脚本与效果评测脚本；
- 沉淀交付 SOP 与排障手册，降低同类客户交付成本。

要求
- 3 年以上面向企业客户的技术交付、实施或技术支持经验；
- 熟悉开放平台集成：OpenAPI、Webhook、OAuth/Token；
- 熟悉 Python，有使用 FastAPI 或类似框架构建服务的经验；
- 了解 Agent、RAG、Prompt 工程，有实际动手经验；
- 能独立对接客户 IT 与业务团队，具备清晰的问题拆解能力。

加分项
- 有 MCP、向量检索或评测集搭建经验；
- 有把高频问题沉淀为标准化交付流程的经验。
